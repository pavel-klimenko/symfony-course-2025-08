## **БИЗНЕС РОЛИ:**

1) **ROLE_ADMIN**

-Полный доступ ко всем CRUD операциям (stores + products).

2) **ROLE_STORE_MANAGER**

-Управляет складами: создавать, редактировать, удалять.
-Может просматривать продукты, но не управлять ими.

3) **ROLE_PRODUCT_MANAGER**

-Управляет продуктами: создавать, редактировать, удалять.
-Может просматривать склады, но не управлять ими.

4) **ROLE_USER**

-Только просмотр (read‑only) складов и продуктов.
